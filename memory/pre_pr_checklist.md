# Чек-лист ревью перед коммитом / PR

Проходится **построчно против diff** (`git diff main...HEAD` или рабочее дерево), каждый пункт — явно: ✅ / ❌ (файл:строка, правило) / — (не применимо). Нарушения исправляются до «ревью завершено». Основа — `CLAUDE.md`, ADR, WCAG 2.2 AA, методика графиков (ADR-0007).

## 1. Объём и архитектура
- [ ] 1.1 Изменение делает то, что просили, без посторонних правок и «заодно».
- [ ] 1.2 Зависимости вниз: `sections → patterns → components → foundations`; `@uix/ui` не импортирует `@uix/charts`; нет циклов.
- [ ] 1.3 Новый компонент — из реального экрана или явного решения владельца; абстракция — не раньше второго применения.
- [ ] 1.4 Компонент не знает активную стилистику/схему (нет `data-theme`/`data-scheme` в компонентах).
- [ ] 1.5 Бизнес-логика отделена от разметки и темы; чистые функции — в `utils/`/`core/` с юнит-тестами.
- [ ] 1.6 Публичный API экспортирован из `index.ts` (компонент + типы); внутреннее — не экспортируется.

## 2. Токены и стили
- [ ] 2.1 Нет необъяснимых чисел: размеры, отступы, радиусы, длительности, прозрачности — токены. Исключение — 0/1/100%, `1px` для sr-only, значения в `@container`/`@media` (там нельзя `var()`) — с комментарием, какой токен.
- [ ] 2.2 Нет сырых цветов (hex/rgb/hsl) в компонентах — только семантические роли `color/*`, `surface/*`.
- [ ] 2.3 У каждого `var(--token)`, от которого зависит видимость (цвет, фон, обводка), — безопасный fallback (системный цвет CSS).
- [ ] 2.4 Все упомянутые токены существуют в `packages/tokens/dist` (нет опечаток).
- [ ] 2.5 Стили — `<style scoped>` внутри `@layer components`; без `!important`, без Tailwind; `:deep()` — только для содержимого слотов/дочерних компонентов.
- [ ] 2.6 Новые токены: DTCG, имя по конвенции (`color/<role>/<state>`, `size/*`…), описание, есть во всех 4 комбинациях, отражены в `docs/tokens.md` и (для Figma) в `docs/figma-todo.md`.

## 3. Mobile-first и адаптивность
- [ ] 3.1 Базовые стили — для 360–390px, расширение — `min-width`; в компонентах — container queries, не media (media — только `prefers-*` и `pointer`).
- [ ] 3.2 Зоны касания интерактивных элементов ≥ 44×44 (`size/44`) или вся плашка кликабельна.
- [ ] 3.3 Нет горизонтального переполнения на 360px (длинные подписи обрезаются/переносятся, `min-inline-size: 0` у grid/flex-детей).
- [ ] 3.4 Скриншот проверен на мобильной и десктопной ширине.

## 4. Доступность (WCAG 2.2 AA)
- [ ] 4.1 Семантика: нативные элементы (button, input, fieldset/legend, table/th scope) или корректные роли ARIA; нет ARIA на элементе без роли.
- [ ] 4.2 У каждого контрола — доступное имя; описание — через `aria-describedby`, не внутри имени.
- [ ] 4.3 Клавиатура: всё достижимо Tab, порядок логичный, стрелки/Home/End где уместно, фокус виден (`:focus-visible`, ≥ 3:1).
- [ ] 4.4 Состояния озвучиваются: `aria-pressed/checked/sort/invalid/busy/current`, живой регион для динамики.
- [ ] 4.5 Смысл не только цветом (иконка, текст, форма).
- [ ] 4.6 Контраст: текст ≥ 4.5:1, крупный/графика/границы контролов ≥ 3:1 — во всех 4 комбинациях (axe в историях + `contrast.test.ts`).
- [ ] 4.7 `prefers-reduced-motion` — анимации выключаются, состояние остаётся различимым.

## 5. Моушн (Liquid Glass)
- [ ] 5.1 Нажатие — скейл (`scale/pressed*`) на пружине (`easing/spring-*`), размеры/раскладка не меняются.
- [ ] 5.2 Длительности и кривые — токены; анимируются `transform/opacity/scale` (не layout-свойства).
- [ ] 5.3 JS-анимация — через `requestAnimationFrame`, отменяется при размонтировании, не запускается на сервере.

## 6. Темы
- [ ] 6.1 Смена `data-theme` и `data-scheme` не требует правок компонента.
- [ ] 6.2 Для новых визуальных компонентов есть матрица 4 схем (`themeMatrix`) с литеральными тегами `["!dev", "!autodocs"]`.

## 7. Vue и TypeScript
- [ ] 7.1 `<script setup lang="ts">`, `defineProps` с JSDoc у каждого пропа, `defineModel`/`defineEmits` типизированы.
- [ ] 7.2 Дефолты-функции (`ValueFormat` и т.п.) — не через `withDefaults` (Vue отдаст функцию как значение) — fallback в коде.
- [ ] 7.3 Локальные имена не затеняют пропсы (`vue/no-dupe-keys`).
- [ ] 7.4 Нет `any`, `@ts-ignore`, непроверенных `!` там, где значение может отсутствовать; `vue-tsc` без ошибок.
- [ ] 7.5 Нет `console.log`, закомментированного кода, TODO без задачи.
- [ ] 7.6 SSR-безопасность: `window`/`document`/`matchMedia`/`ResizeObserver` — только в `onMounted`; `useId()` для id.
- [ ] 7.7 Ключи `v-for` стабильны и уникальны; нет мутаций пропсов.
- [ ] 7.8 Подписи и тексты по умолчанию — по-русски и переопределяемы пропсами.

## 8. Графики (ADR-0007)
- [ ] 8.1 Форма выбрана по задаче; ≤ 8 серий (донат ≤ 6), хвост — «Другое».
- [ ] 8.2 Цвет — по сущности (индекс в полном списке), скрытие/фильтр не перекрашивает; статус-цвета — только для статуса, с иконкой и текстом.
- [ ] 8.3 Тонкие метки: линия 2px, столбец ≤ 24px, скругление только у конца-данных, зазор 2px, кольцо 2px у точек; сетка сплошная; одна ось Y.
- [ ] 8.4 Легенда при ≥ 2 сериях; текст — токены текста, не цвет серии; `tabular-nums` только в колонках/осях.
- [ ] 8.5 Подсказка/перекрестье + то же с клавиатуры + живой регион; табличный двойник; пустое состояние; загрузка без скелетона.

## 9. Тесты
- [ ] 9.1 Чистая логика — юнит-тест (Vitest): формат, математика, преобразования, граничные случаи.
- [ ] 9.2 Каждый компонент — истории с play-тестами поведения (клик, клавиатура, v-model/события) и axe.
- [ ] 9.3 Состояния loading/empty/error/disabled/focus — в историях, где применимы.
- [ ] 9.4 Тест проверяет поведение, а не реализацию; ожидания посчитаны, а не подогнаны.

## 10. Документация и Storybook
- [ ] 10.1 Описание компонента в Docs (назначение, поведение, a11y); controls для значимых пропсов, служебные скрыты.
- [ ] 10.2 `docs/components.md` — какие токены использует; ADR/roadmap/CLAUDE.md «Текущий этап» — актуальны.
- [ ] 10.3 Страница Docs открывается без зависаний (истории с открытыми панелями — `!autodocs`).

## 11. Сборка и поставка
- [ ] 11.1 Зелёные: `pnpm lint`, `pnpm -r typecheck`, `pnpm -r test`, `pnpm build-storybook`.
- [ ] 11.2 Зависимости: новые — в нужном пакете, версии закреплены lock-файлом, нет лишних.
- [ ] 11.3 Нет секретов, временных файлов (`.tmp-*`), артефактов сборки в коммите.
