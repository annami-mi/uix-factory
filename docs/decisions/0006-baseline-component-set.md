# ADR-0006: Базовый набор компонентов кита

Статус: принято 2026-09-24

## Контекст

Правило проекта (CLAUDE.md): «Новый компонент появляется только из реального экрана — не потому что есть в популярных дизайн-системах». На 2026-09-24 в ките были Button, Input, Select, Textarea, Checkbox и их части — до первого реального экрана (эталонный лендинг, шаг 9–11 roadmap) оставалось далеко, а каждый экран потребует одних и тех же базовых компонентов.

Решение владельца проекта: собрать **базовый набор, нужный для полноценной разработки лендингов → сайтов → магазинов → SaaS**, заранее, и дать право на самостоятельные решения по составу и деталям.

## Решение

Правило «только из реального экрана» **осознанно переопределено для базового набора** — компонентов, которые встретятся в любом продукте фабрики. Для всего остального (секции, паттерны, специфичные компоненты) правило остаётся в силе.

Состав (все — токен-первые, в Figma отрисован только Button/Field/Input/Select, см. `docs/figma-todo.md`):

| Группа | Компоненты |
|---|---|
| Действия | Button (+ `ghost`), IconButton, Link |
| Формы | FormField, Field, Input, Textarea, Select, NumberField, Checkbox, RadioGroup, Switch |
| Раскладка и текст | Container, Stack, Grid, Section, Heading, Text, Divider |
| Контент | Card, Badge, Avatar, Skeleton, Accordion, Tabs |
| Оверлеи и обратная связь | Sheet, Dialog, Tooltip, DropdownMenu, Toast (`<Toaster />` + `useToast`), Alert, Spinner |
| Навигация | Breadcrumbs, Pagination |

Общие решения набора:

- **Поведение сложных компонентов — Reka UI** (Select, Dialog, Sheet, Tooltip, DropdownMenu, Toast, Tabs, Accordion, Pagination, NumberField); простые — на нативном HTML (Checkbox, RadioGroup, Switch, Link, Breadcrumbs).
- **Мобильный — первичен**: панели выбора и диалоги на узком экране — шторка (Sheet), на десктопе — всплывашка/окно (`presentation: auto`); зоны касания ≥ 44px; раскладка без media query (clamp, auto-fit).
- **Liquid Glass**: пружинная анимация нажатий и появления, плашки-материалы через токены `surface/*`; плоская стилистика подставляет `none`/`transparent`.
- **Доступность как тест**: каждая история — тест с axe во всех комбинациях стилистика × схема; контраст ключевых пар ролей проверяется ещё и тестом токенов (`packages/tokens/test/contrast.test.ts`).

## Отложено (появится с реальным экраном)

- **Таблица данных** (SaaS) — сортировка, выбор строк, адаптив под мобильный — отдельная задача.
- **Combobox с поиском** и **DatePicker** — формы с поиском по длинным спискам и датами.
- **Секции лендинга** (Header + Drawer, Hero, Footer, LeadForm) — шаги 10–11 roadmap, в `packages/sections`.
- **Смахивание шторки вниз** — жест; сейчас закрывается тапом по фону, Esc или кнопкой.

## Последствия

- Для базового набора Figma отстаёт от кода: макеты перечислены в `docs/figma-todo.md`, источник истины — код (ADR-0003).
- Новые компоненты вне набора — по-прежнему только из реального экрана.
