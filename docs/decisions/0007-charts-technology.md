# ADR-0007: Графики и визуализация данных для SaaS

Статус: принято 2026-09-24

## Контекст

SaaS-продуктам фабрики нужны графики статистики, KPI, таблицы данных и фильтры. Требования: современная анимация (канон Liquid Glass — пружины), адаптивность (mobile-first, касание), темы (стилистика × схема из токенов, ADR-0005), доступность (axe во всех схемах, клавиатура, табличный двойник), SSR-совместимость Nuxt.

## Решение

**Свои SVG-компоненты на Vue + математика d3** (`d3-scale`, `d3-shape`, `d3-array`), отдельный пакет `@uix/charts`.

- Рендер — шаблоны Vue в SVG: каждая метка — DOM-узел, видимый axe и скринридеру; цвета — CSS-переменные токенов, смена `data-theme`/`data-scheme` без перерисовки из JS.
- d3 — только расчёт (шкалы, линии, стек, «красивые» деления), без d3-selection/transition: DOM принадлежит Vue.
- Анимация — пружина данных в JS (`useSpring`): при монтировании значения растут от базовой линии, при смене данных — перетекают из старых в новые (фильтр, период). Интерактив (перекрестье, подсказка) — CSS-пружины из токенов. `prefers-reduced-motion` — без анимации.
- Размер — `ResizeObserver` контейнера: ширина от раскладки, высота — токен `size/chart/*`; число делений осей — от ширины. На касание: перетаскивание по графику двигает перекрестье, вертикальный скролл страницы не блокируется.

**Методика — руководство по визуализации данных (dataviz):** форма выбирается до цвета; тонкие метки (линия 2px, столбец ≤ 24px со скруглённым концом 4px, зазор 2px в цвет фона, кольцо 2px у точек); сетка — сплошная тонкая; легенда при ≥ 2 сериях, прямые подписи выборочно; подсказка с перекрестьем на линиях и на каждой метке у столбцов, та же информация — с клавиатуры; **табличный двойник у каждого графика**; одна ось Y (никаких двух шкал); цвет следует за сущностью, а не за рангом (фильтр не перекрашивает).

**Палитра** — эталонная из руководства, проверена скриптом валидатора на фонах карточек всех четырёх схем (светлота, хрома, различимость при протанопии/дейтеранопии ΔE ≥ 8 для соседних, ≥ 15 без симуляции, контраст). Фирменная палитра Figma (системные цвета iOS) не проходит: жёлтый вне диапазона светлоты, зелёный/розовый сливаются при дейтеранопии (ΔE 5.7). Токены: `color/chart/series/1…8`, `color/chart/sequential/1…7` (в тёмной схеме якорь перевёрнут), `color/chart/status/*`, `color/chart/{grid,axis,muted}`. Для форм «все пары» (разброс, тепловая карта по категориям) — не больше трёх серий.

## Состав

- Основа: `ChartCard` (figure, заголовок, легенда, переключатель «График / Таблица», загрузка без мигания — прежний рендер приглушён, пустое состояние), `ChartLegend`, подсказка, табличный двойник.
- Графики: `LineChart` (+ area, выделение одной серии), `BarChart` (вертикальный/горизонтальный, группы/стек), `DonutChart` (доля от целого, ≤ 6 сегментов), `Sparkline`, `StatTile` (+ ряд KPI), `Meter`, `Heatmap`.
- SaaS (в `@uix/ui` — не графики, а обычный UI): `DataTable` (сортировка, выбор строк, липкая шапка, карточки в узком контейнере), `PeriodSelect` (пресеты и свой диапазон). Ряд KPI — `Grid` из `@uix/ui`, отдельного компонента нет.

## Альтернативы и почему отклонены

- **ECharts / Chart.js (canvas)** — пиксели вместо DOM: axe и скринридер не видят меток, темы — объекты JS, а не токены, нет серверного рендера; большой бандл.
- **ApexCharts / Unovis (SVG)** — собственный визуальный язык и анимации; привести к Liquid Glass, токенам и правилам методики — бороться с библиотекой при каждом обновлении.
- **Чистый d3 (selection/transition)** — конкурирует с Vue за DOM.

## Последствия

- Каждый новый тип графика — компонент в `@uix/charts` с историями и матрицей по схемам (axe) и табличным двойником.
- Figma: палитра графиков — токен-first (`docs/figma-todo.md`).
