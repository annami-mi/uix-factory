# UIX Factory

Кит компонентов для коммерческих веб-продуктов: лендинги → сайты → магазины → SaaS. Компоненты пишутся один раз; визуальную индивидуальность проекта задаёт **стилистика** — набор значений токенов, а не переписывание компонентов.

## Принципы

- **Mobile-first.** Всё проектируется и проверяется сначала на 360–390px (превью здесь по умолчанию — 390px), десктоп — расширение. Интерактивные элементы — комфортные для тача (кнопка — 48px).
- **Стилистика = токены.** Компонент ссылается только на роли (`--surface-accent-default-bg`, `--color-text-primary`), не на значения. Смена `data-theme` не требует правок компонента — это критерий приёмки.
- **Доступность — часть готовности.** Каждая история проверяется axe; видимый фокус с клавиатуры, `prefers-reduced-motion`.
- **Флагманская стилистика — «Жидкое стекло»** (канон Liquid Glass): материал поверхности, блики, пружинная анимация. Плоская `neutral` подставляет `none`/`transparent` в те же роли.
- **Каждая стилистика — в светлой и тёмной схеме.** Без `data-scheme` схема следует настройке системы.

## Что в ките

Базовый набор (ADR-0006): **действия** (Button, IconButton, Link), **формы** (Input, Textarea, Select, NumberField, Checkbox, RadioGroup, Switch), **раскладка и текст** (Container, Stack, Grid, Section, Heading, Text, Divider), **контент** (Card, Badge, Avatar, Skeleton, Accordion, Tabs), **оверлеи и обратная связь** (Dialog, Sheet, Tooltip, DropdownMenu, Toast, Alert), **навигация** (Breadcrumbs, Pagination).

## Как смотреть

- **Стилистика** — кисточка в тулбаре (`glass`, `neutral`) → `data-theme` на `<html>`.
- **Схема** — кнопка контраста в тулбаре (светлая / тёмная / как в системе) → `data-scheme`. Каждая стилистика обязана иметь обе схемы (ADR-0005).
- **Viewport** — иконка устройства в тулбаре: 360 / 390 / 768 / 1440.
- **Foundations** — токены (цвета, типографика, отступы, моушн), сгенерированы из `@uix/tokens`.
- **Components** — у каждого компонента страница Docs (пропсы, слоты, все состояния) и истории. Истории — это тесты: их play-функции и axe прогоняются в Vitest (панель Testing внизу слева или `pnpm test:stories`).

## Подключение в приложении

```ts
import "@uix/ui/styles.css"; // слои каскада, токены всех тем, шрифт Golos Text
import { Button, Toaster } from "@uix/ui"; // <Toaster /> — один раз в layout, если нужны уведомления
```

```html
<html data-theme="glass" data-scheme="dark">  <!-- без data-scheme — по настройке системы -->
```
