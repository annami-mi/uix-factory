# Типографика

Шрифт — **Golos Text** (400 / 500 / 600), раздаётся из `@uix/ui` через `@fontsource/golos-text`, без внешних запросов. Стили — `type/<роль>/<размер>`, размеры — буквами `xs · s · m · l` (2026-09-25). По значениям совпадают со стилями Figma, но имена другие: `body/m` — основной текст 16px, `s` — 14, `xs` — 12, `l` — 18 (только в коде); заголовки `heading/l · m · s`. Соответствие имён Figma → код — в `docs/figma-todo.md`.

В CSS каждый стиль раскладывается на четыре переменные: `--type-label-s-font-family`, `-font-weight`, `-font-size`, `-line-height`. Образцы ниже рисуются этими переменными вживую.

<table>
  <thead>
    <tr><th>Стиль</th><th>Образец</th><th>Размер / интерлиньяж / вес</th></tr>
  </thead>
  <tbody>
    {typeStyles().map((s) => (
      <tr key={s.name}>

        </td>
        <td><code>{s.size} / {s.lineHeight} / {s.weight}</code></td>
      </tr>
    ))}
  </tbody>
</table>
